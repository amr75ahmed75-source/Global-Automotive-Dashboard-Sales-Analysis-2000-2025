🚗 New Project: Global Automotive Dashboard — Sales Analysis 2000–2025

I built an interactive Power BI dashboard analyzing global automotive sales, pricing, and product trends across 44 brands and 25 years of data.

📊 What it covers:
✅ 42.32M units sold, $1.54T in total revenue across global markets
✅ Regional performance analysis (Saudi Arabia, UAE, Egypt & more leading MENA demand)
✅ Brand-level sales volume & revenue rankings (Ford leads with 7.0M units)
✅ Fuel type mix analysis — Petrol, Hybrid, Diesel & Electric adoption trends
✅ Pricing trend from 2000–2025, with a sharp rise since 2020
✅ Fully interactive decomposition tree for ad-hoc drill-down (Region → Brand → Car Type → Class → Fuel → Transmission)
✅ Niche & luxury brand performance (Porsche, Ferrari, Rolls-Royce & more)

🔍 Key finding: Sedans are the fastest-growing car type (+4.1M units), while used vehicles make up over 91% of total sales volume — highlighting how large the secondary market really is.

🛠️ Built entirely in Power BI: custom DAX measures, geo-mapping, and a fully interactive 5-page report.

This project is part of my growing portfolio in large-scale sales & market analytics. Always happy to connect and discuss automotive/retail analytics!
